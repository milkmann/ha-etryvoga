## 🚀 Чому саме ця інтеграція?

Стандартна інтеграція `ukraine_alarm` з ядра Home Assistant надає лише загальний факт увімкнення сирени по районах. **Інтеграція «єТривога» виводить безпеку вашої оселі на принципово новий рівень:**

- ⚡ **Миттєве отримання даних (Real-time SSE Push):** Завдяки потоковому підключенню до `api/map/live` події надходять із затримкою **менше 1 секунди**, без необхідності постійно навантажувати сервер повторними HTTP-запитами.
- 🎯 **Тактичні деталі загроз:** Ви точно знаєте, **що летить, напрямок та вектор небезпеки** (наприклад: *«💣 Загроза КАБ з південно-східного напрямку»*, *«🛸 БПЛА курсом на передмістя»*, *«🚀 Ракетна небезпека для регіону»*).
- 🟡 **Рівні небезпеки:** Розпізнавання **жовтого** (загроза дронів/Шахедів) та **червоного** (ракети, КАБ, загальна тривога) рівнів тривоги.
- 🏢 **Зручний 3-рівневий майстер налаштування (UI):** Вибір Області ➔ Району ➔ конкретного Населеного пункту / Міста.
- ⚡ **Event Entity для автоматизацій:** Новий стандарт Home Assistant — підписка на дискретні події (`alarm_started`, `threat_detected`) без складних шаблонів.
- 📦 **Готові шаблони (Blueprints):** Сповіщення в Telegram, сигналізація смарт-лампами та голосові сирени (TTS) на колонки з коробки.

## 📊 Сутності (Entities), які створюються в Home Assistant

Після додавання вашого району створюється віртуальний пристрій **«єТривога: <Ваш район>»** з повним комплектом сенсорів:

### 🔴 Бінарні сенсори (`binary_sensor`)

| Сутність | Назва | Device Class | Опис та додаткові атрибути |
| :--- | :--- | :--- | :--- |
| `binary_sensor.<id>_air_alert` | **Повітряна тривога** | `safety` | `on` (Небезпечно) коли оголошено тривогу, `off` (Безпечно). Атрибути: `alert_level` (yellow/red), `duration_minutes`. |
| `binary_sensor.<id>_kab_threat` | **Загроза КАБ** | `safety` | `on` (Небезпечно) при загрозі керованих авіабомб. Атрибути: `origins` (звідки летить), `events`. |
| `binary_sensor.<id>_drone_threat` | **Загроза БПЛА / Шахедів** | `safety` | `on` (Небезпечно) при фіксації ударних дронів у зоні контролю. |
| `binary_sensor.<id>_missile_threat` | **Ракетна небезпека** | `safety` | `on` (Небезпечно) при загрозі крилатих або балістичних ракет. |
| `binary_sensor.<id>_artillery_threat` | **Загроза артобстрілу** | `safety` | `on` (Небезпечно) для прифронтових та прикордонних громад. |
| `binary_sensor.<id>_recon_threat` | **Розвідувальний БПЛА** | `safety` | `on` (Небезпечно) при активності розвідувальних дронів коригування. |
| `binary_sensor.<id>_explosion_threat` | **Повідомлення про вибух** | `safety` | `on` (Небезпечно) при надходженні верифікованих повідомлень про вибухи. |

### 🟡 Сенсори стану (`sensor`)

| Сутність | Назва | Значення (State) | Опис та застосування |
| :--- | :--- | :--- | :--- |
| `sensor.<id>_alert_level` | **Рівень тривоги** | `clear` / `yellow` / `red` | Зручно для зміни кольору RGB-підсвічування будинку. В атрибутах передається точний hex-код: `#10B981`, `#EAB308`, `#DC2626`. |
| `sensor.<id>_tactical_summary` | **Тактичне зведення** | Текст | Готовий структурований текст для виводу на екран або голосового озвучення (TTS) на колонках. |
| `sensor.<id>_alert_duration` | **Тривалість тривоги** | Число (хвилини) | Лічильник часу поточної тривоги. |
| `sensor.<id>_active_threats_count` | **Кількість активних загроз** | Число | Загальна кількість актуальних тактичних небезпек для вашого сектору. |

### ⚡ Сутність подій (`event`)

* `event.<id>_threat_event` — генерує дискретні події:
  * `alarm_started` — початок тривоги (передає рівень, час, зведення);
  * `alarm_cancelled` — відбій тривоги (передає тривалість у хвилинах);
  * `threat_detected` — зафіксовано нову загрозу (передає напрямок, тип, звідки пущено).

## 🛠️ Встановлення через HACS

### Крок 1. Додавання репозиторію в HACS
1. Відкрийте Home Assistant ➔ перейдіть у **HACS**.
2. У правому верхньому кутку натисніть меню (три крапки) ➔ **Custom repositories** (Користувацькі репозиторії).
3. Вставте посилання:
   ```text
   https://github.com/milkmann/ha-etryvoga
   ```
4. У полі **Category** (Категорія) виберіть **Integration** (Інтеграція).
5. Натисніть **Add** (Додати).

### Крок 2. Завантаження та налаштування
1. Знайдіть у пошуку HACS інтеграцію **eTryvoga (єТривога)** та натисніть **Download** (Завантажити).
2. Перезавантажте Home Assistant.
3. Перейдіть у **Налаштування** ➔ **Пристрої та служби** ➔ **Додати інтеграцію**.
4. Знайдіть у списку **eTryvoga (єТривога)**:
   * **Крок 1 (Область):** Оберіть вашу область (доступні всі 26 областей та регіонів України).
   * **Крок 2 (Рівень моніторингу):** Оберіть потрібний рівень:
     - *«{Область} (вся область)»* — загальна тривога по всьому регіону;
     - *«м. {Місто} (місто)»* — прямий вибір обласного центру (Київ, Харків, Одеса, Дніпро, Запоріжжя, Львів тощо);
     - *Територіальний район* області.
   * **Крок 3 (Населений пункт / Громада):** Якщо обрано район, ви можете обрати весь район цілком або вказати конкретне місто, селище чи громаду для точкового контролю загроз.
   * Позначте прапорець *«Враховувати загрози в межах області»*, якщо бажаєте отримувати сповіщення про вектор руху БПЛА чи ракет по сусідніх секторах вашого регіону.

## 💡 Готові автоматизації (Blueprints)

Інтеграція постачається з готовими офіційними шаблонами автоматизацій:

1. **Сповіщення в Telegram (`telegram_alerts.yaml`):**
   * Миттєве красиве повідомлення при оголошенні тривоги.
   * Оперативні апдейти при фіксації КАБ чи Шахедів з напрямком.
   * Повідомлення про відбій із зазначенням тривалості.
2. **Сигналізація кольором розумного світла (`rgb_lights_alert.yaml`):**
   * Вмикає **жовтий колір** при загрозі дронів.
   * Вмикає **червоний пульсуючий колір** при загрозі ракет чи КАБ.
   * Вмикає **зелений колір на 15 секунд** і повертає попередній стан при відбої.
3. **Голосове попередження через колонки (`voice_warning_tts.yaml`):**
   * Озвучує попередження через Google Cast / HomePod / AirPlay при виявленні КАБ.
